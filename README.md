# Two Palms West — Collaboration Proposal

Englische, weiße Präsentation als persönliche Kollaborationsanfrage an Chandra und Two Palms West. `index.html` bettet das vollständige Website-Konzept `website.html` ein; Desktop-/Mobilvorschau, Vergrößerung und Film-Storyboard sind interaktiv. Beide Seiten sind statisch und für GitHub Pages vorbereitet.

## Ansehen

`index.html` direkt im Browser öffnen. Es gibt keine Installation und keinen Build-Schritt.

Für eine lokale Vorschau aus diesem Ordner:

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

Danach `http://127.0.0.1:4174/` öffnen.

## GitHub Pages

Den **Inhalt dieses Ordners** in die oberste Ebene eines neuen GitHub-Repositories übernehmen. Unter **Settings → Pages → Build and deployment** `Deploy from a branch`, `main` und `/(root)` wählen.

Alle Dateien, Schriften und Bilder sind lokal eingebunden. Die internen Pfade sind relativ, daher funktioniert die Seite auch unter `https://username.github.io/repository/`.

## Inhalt und Quellen

- Ausgangspunkt: die beiden vom Nutzer bereitgestellten HTML-Entwürfe `two-palms-west-onepage.html` und `two-palms-west-presentation.html`.
- Portraits: vom Nutzer bereitgestellte Dateien von Ninie Rosenfeld-Di Lenardo und Alexander Friedmann; für die Website verkleinert und als JPEG optimiert.
- Typografie: DM Sans und Instrument Serif, entsprechend der bestehenden Gallery-House-Gestaltungsrichtung.
- Inhaltliche Referenzen: [Chandra](https://chandra.tv/), [Two Palms West](https://twopalmswest.com/), [Senses Studio](https://sensesstudio.photography/) und [WEBDESIGN by AF](https://www.webdesign-af.com/).
